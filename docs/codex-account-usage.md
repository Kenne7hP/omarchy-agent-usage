# Codex account usage

The extension uses the existing initialized app-server session, with the
existing Codex login. It adds `account/usage/read` without a `threadId` to
request account-wide activity. It does not create a separate HTTP client or
copy credentials.

The source installation checked the schema generated by Codex **0.166.0**
against the [official app-server account usage documentation](https://learn.chatgpt.com/docs/app-server#7-token-usage-chatgpt).
That version accepts empty parameters. Other versions require verification.

`dailyUsageBuckets[].startDate` and `.tokens` map to a separate `accountUsage`
object. The panel shows seven days ending with the local calendar's Today.
Missing dates remain unavailable, not zero. Unsupported requests or query
failures leave valid subscription limits and local statistics intact.

Account token counts are not added to local tokens or exported in device sync
snapshots. The local/device chart shows three days; collected history is retained.

The service does not specify bucket-boundary timezone or update delay in the
inspected schema. Queried time is when the request completed, not a data cutoff.
An absent current-day bucket cannot be interpreted as no usage today. Hover
details expose the date, exact value and freshness limitation.
